# チケット価格の収集メモ

`show_tickets` に入れる値をここで集める。**マスタ (みんなで共有する事実)** なので、
値は必ず一次ソース (公式サイト / 公式のチケット受付ページ / 公式アーカイブ) から取る。

## 出力の形 (TSV・ヘッダなし)

```
show_id	kind	name	price	is_estimate	note	source_url
```

| 列 | 中身 |
|---|---|
| `show_id` | `shows_<brand>.tsv` の 1 列目をそのまま |
| `kind` | `live` / `stream` / `live_viewing` のどれか |
| `name` | 券種名を**公式の表記そのまま** (`全席指定` / `立見指定` / `ステージサイド席` / `アリーナ席` / `配信` / `配信 (アーカイブ付き)` …) |
| `price` | 円の整数。**税込・手数料抜きの定価**。カンマや「円」は入れない |
| `is_estimate` | `0` = 公式に出ていた額、`1` = 推定 (同じツアーの他日から当てた等) |
| `note` | 当日券・通し券・特典・有効期間など、額に添える補足 (無ければ空) |
| `source_url` | その額が載っているページ。**行ごとに必須** |

## 決め事

- **分からない公演は行を作らない**。空欄や 0 円を入れない (価格帯が静かに狂う)。
- 同じツアーで日によって額が違うことがある (会場・座席構成が違う)。**日ごとに確認**し、
  確認できない日は `is_estimate=1` にして note に「同ツアー <日付> の公演と同額と推定」と書く。
- 先行・一般・当日で額が違う場合、**行にするのは一般発売の定価**。当日券は note へ。
- 配信は「アーカイブ付き」「見逃し延長」などで額が分かれることがあるので、それぞれ別の行にする。
- 通し券 (2 日通しの配信等) は公演単位にならないので行にせず、各日の note に書く。
- 無料公演・抽選招待のみの公演は行を作らない (note を書く場所が無いため)。

## 取り込み

集まった TSV は `tools/import_show_tickets.py` で `db/master.sql` と同梱 DB に入れる。
CloudKit への push はスキーマを production に反映したあと。
