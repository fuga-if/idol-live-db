# 会場マスタの判断データ

`shows.venue` は自由文字列で、同じ会場が最大 8 通りに割れていた
(例: 幕張メッセ = `千葉・幕張メッセイベントホール` / `幕張イベントホール` / `幕張メッセ` …)。
会場を **ID で管理** し、名前が変わっても履歴が分断されないようにするための判断データを置く。

生成スクリプトは `Scripts/venues/`（ローカル運用・git 管理外）。
このディレクトリには **人が下した判断と、その出典** だけを残す。

## ファイル

| ファイル | 中身 |
|---|---|
| `venue_overrides.json` | 機械分解では決まらない判断。改名・別表記・ホール正式名・都道府県の補完 |
| `venue_capacity.json` | キャパ。**出典が取れたものだけ**書く。裏取りできていない施設は載せない (NULL のまま) |

## 方針

- **表示は公演日時点の名前。** 改名は `venue_names` に有効期間つきで持つ。
  2021 年の公演は「武蔵野の森総合スポーツプラザ」、2026 年は「京王アリーナTOKYO」と出る。
- **施設とホールを分ける。** `venues` = 施設 / `shows.hall` = ホール。
  「幕張メッセでやったライブ全部」を施設単位で串刺しできる。
- **配信は会場ではない。** `venue_id` は持たせず `shows.stream_platform` へ逃がす。
- **キャパは構成で変わる。** さいたまスーパーアリーナはスタジアムモード 37,000 /
  アリーナモード 22,500 と倍近く違うため、`venue_halls` 側でも持てるようにする。
- **推測値を入れない。** 出典が取れないキャパ・都道府県は NULL のままにして、後から埋める。

## 現状

- 396 文字列 → 施設 272 件 + 配信のみ 89 件
- キャパ登録済み 5 施設 (上位施設から順次追加)
- 都道府県が埋まっていない施設 44 件 (多くは海外会場・非公開会場)
